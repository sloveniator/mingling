🔗 渠道与服务配置 能力服务商（拉取模式）· 外部服务

两类配置都决定「用哪个服务商 / 渠道」：① 能力服务商为各内部能力指定 AstrBot 已配置服务商；② 外部服务为每个外部 API 选服务商或填自有凭据。两者留空均走 AstrBot 默认。

🎯

能力服务商（拉取模式）

两种模式互斥（切换即清空另一项），对应两个独立渠道：① 拉取模式＝只选 AstrBot 已配置的服务商（或手输 Provider ID），模型跟随该服务商默认；② 自定义＝填自有 Key / 接口，模型从顶部「模型统一配置」区拉取的列表中选择，独立调用不依赖 AstrBot 服务商。留空均走 AstrBot 默认。

命灵通过该地址拉取「能力服务商」列表（结构稳定、明确带 Provider ID）。公网/自签证书地址可填，命灵会自动跳过证书验证。

🔌

外部服务

每个服务可二选一，两种模式互斥（切换即清空另一项）：① 拉取模式＝在「服务商 (AstrBot Provider)」里选 AstrBot 已配置的服务商，留空则自动沿用 AstrBot 默认服务商；② 自定义＝填自有 Key / 接口 / 模型，下拉选中「已拉取的模型」后以该模型独立调用，不再依赖默认服务商的默认模型。模型名下拉仅决定调用哪个模型，服务商（或 Key/接口）决定走哪个渠道。
